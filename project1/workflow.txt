Phase 1 — Application:
1. Clone GitHub repository
2. Add Dockerfile
3. docker build
4. docker run
5. Verify application in browser

Phase 2 — ECR:
1. Create ECR Repository
2. aws ecr create-repository \
  --repository-name brain-tasks-app \
  --region ap-south-1
3. Test Pushing Manually
4. aws sts get-caller-identity
5. suppose it gives 123456789012 then
6. aws ecr get-login-password --region ap-south-1 | \
docker login \
--username AWS \
--password-stdin \
123456789012.dkr.ecr.ap-south-1.amazonaws.com
7. Tag the image
docker tag brain-tasks-app:latest \
123456789012.dkr.ecr.ap-south-1.amazonaws.com/brain-tasks-app:latest
8. docker push \
123456789012.dkr.ecr.ap-south-1.amazonaws.com/brain-tasks-app:latest
9. Verify image in ECR

Phase 3 — EKS:
1.Install/check
aws --version
kubectl version --client
eksctl version
2. aws configure
3. Verify by aws sts get-caller-identity
4. Create EKS cluster 
eksctl create cluster \
  --name brain-tasks-cluster \
  --region ap-south-1 \
  --nodes 2 \
  --node-type t3.small
5. Verify EKS
eksctl get cluster
kubectl get nodes
kubectl get pods -A
6. Update Kubeconfig
aws eks update-kubeconfig \
  --region ap-south-1 \
  --name brain-tasks-cluster
7. kubectl get nodes
8. Before creating CodePipeline, test Kubernetes separately. 
9. Create K8 dir inside it make 2 files 
k8s/
├── deployment.yaml
└── service.yaml
10. kubectl apply -f k8s/deployment.yaml
11. kubectl apply -f k8s/service.yaml
12. kubectl get pods
13. kubectl get service
14. Open the browser and paste the External-Ip(ALB)

Phase CodeBuild #1:
1. Add buildspec.yml to the root of the GitHub Repo 
2. CodeBuild environment AWS Console → CodeBuild → Build projects → Create build project
3. Project name: brain-tasks-build
4. Environment :
Managed image
EC2
Amazon Linux
Standard
5. And enable Privileged
6. Environment Variables :
AWS_DEFAULT_REGION : ap-south-1
AWS_ACCOUNT_ID : YOUR_ACCOUNT_ID
IMAGE_REPO_NAME : brain-tasks-app
IMAGE_TAG : latest
7. CodeBuild #1 IAM Policy:
AmazonEC2ContainerRegistryPowerUser
         (or)
ecr:GetAuthorizationToken
ecr:BatchCheckLayerAvailability
ecr:CompleteLayerUpload
ecr:InitiateLayerUpload
ecr:PutImage
ecr:UploadLayerPart
8. Click start Build
9. Watch Build Logs
10. Then check ECR → brain-tasks-app Image should exists

Phase CodeBuild #2:
1. Add deploy-buildspec.yml to the root of the GitHub Repo
2. CodeBuild #2 variables
AWS_DEFAULT_REGION : ap-south-1
AWS_ACCOUNT_ID = 123456789012
EKS_CLUSTER_NAME = brain-tasks-eks
3. CodeBuild #1 IAM Policy:
Access EKS

Phase CodePipeline:
1. CodePipeline --> Create pipeline --> Choose a custom pipeline.
2. The flow should be:
SOURCE
   ↓
BUILD
   ↓
DEPLOY
3. Source stage:
Connect your GitHub account/repository.
for example:
Repository : your-repository
Branch : main
4. Build stage:
Select: AWS CodeBuild
Project: brain-tasks-build
This invokes: docker build --> docker tag --> docker push
5. Deploy stage:
Select : AWS CodeBuild
Project : brain-tasks-deploy
6. This executes: 
aws eks update-kubeconfig
kubectl get nodes
kubectl apply
kubectl rollout status
